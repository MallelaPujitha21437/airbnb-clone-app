# AI sub-agent / skill configuration

This directory is included because the assignment asks for AI sub-agent/skill configuration files.

## Roles

- `requirements-reviewer`: checks the PDF-derived requirements.
- `ui-reviewer`: checks visual and interaction parity against the supplied documentation.
- `accessibility-reviewer`: checks keyboard navigation, labels, focus-visible states and dialogs.
- `api-reviewer`: checks API validation and dynamic state.
- `submission-reviewer`: checks that architecture and AI workflow documents are present.

The actual application remains a normal React + Express project so it can be run without any AI platform.
